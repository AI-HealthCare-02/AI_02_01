## 한국인 균형 식사 가이드

### 한식 영양 특성
전통 한식은 채소·곡물·발효식품 중심으로 식이섬유와 다양한 미량 영양소가 풍부하다.
그러나 국·찌개·김치·젓갈 등 발효·저장식품의 나트륨 함량이 높아 심혈관 위험군에서는 주의가 필요하다.

### 한국인 하루 권장 영양소 기준 (성인 기준)
- 칼로리: 남성 2,500kcal, 여성 2,000kcal (활동량에 따라 조절)
- 탄수화물: 55~65% (300~350g)
- 단백질: 15~20% (60~80g)
- 지방: 15~30% (40~65g)
- 나트륨: 2,000mg 미만 (WHO) / 한국인 평균 섭취량 3,500mg으로 초과 상태
- 식이섬유: 20~30g/일

### 나트륨 함량 높은 주요 한식 (1인분 기준)
- 라면: 1,900mg (국물 포함)
- 짬뽕: 2,400mg
- 순두부찌개: 1,500mg
- 김치찌개: 1,200mg (건더기 위주 시 700mg)
- 된장찌개: 900mg
- 김치: 1컵(150g) 기준 700mg
- 젓갈: 1큰술 기준 300~500mg

**나트륨 줄이는 실천법**
- 국·찌개는 국물보다 건더기 위주로 섭취
- 간장·고추장·된장 사용량 1/2로 줄이기
- 나트륨이 낮은 양념: 식초·레몬즙·허브·마늘

### 균형 한식 구성 예시

**낮음·보통 위험군 — 균형 유지 식사**
- 잡곡밥(150g) + 된장찌개(건더기 위주) + 두부구이 + 시금치나물 + 김치(소량)
- 현미밥(150g) + 미역국 + 고등어구이 + 브로콜리볶음 + 깍두기(소량)

**중간 위험군 — 나트륨 조절 식사**
- 현미밥(120g) + 채소국(맑은국) + 닭가슴살구이 + 나물 2가지 + 요거트
- 잡곡밥(120g) + 두부된장국(저염) + 연어구이 + 샐러드(드레싱 적게)

**높음·매우높음 위험군 — 치료식 수준 식사**
- 귀리밥(100g) + 채소수프(무염) + 생선구이 + 채소 3가지 + 과일
- 통밀빵(1.5장) + 두부 + 아보카도샐러드 + 견과류 소량

### 식품별 영양 강점

**단백질 공급원 (포화지방 낮음)**
- 두부(100g): 단백질 8g, 포화지방 0.5g, 칼로리 76kcal
- 달걀흰자(1개): 단백질 3.5g, 지방 0g
- 닭가슴살(100g): 단백질 23g, 지방 1g, 칼로리 106kcal
- 고등어(100g): 단백질 20g, 오메가-3 2.5g

**식이섬유 공급원**
- 귀리(50g): 식이섬유 4g, β-글루칸 1.5g (콜레스테롤 강하 효과)
- 브로콜리(100g): 식이섬유 2.6g, 비타민 C 89mg, 칼륨 316mg
- 시금치(100g): 식이섬유 2.2g, 칼륨 558mg, 엽산 194mcg

**항산화·미량 영양소 공급원**
- 파프리카(빨강, 100g): 비타민 C 190mg (하루 권장량 220%)
- 당근(100g): 베타카로틴 8,285mcg (비타민 A 전구체)
- 토마토(100g): 라이코펜 2,573mcg (LDL 산화 억제)

### 건강한 조리법 전환 가이드
- 튀기기 → 굽기·찌기·데치기 (칼로리 30~50% 감소)
- 볶음 시 식용유 대신 올리브유 사용 (포화지방 → 단일불포화지방)
- 멸치·다시마 육수 사용 시 소금 50% 절약 가능
- 고추장·간장·된장 기반 소스 → 식초·레몬·허브 기반으로 전환

### 한 끼 칼로리 기준
- 아침·저녁 식사: 500~600kcal
- 점심 식사: 700~800kcal
- 건강 위험군 목표 칼로리: 총 1,600~1,800kcal/일 (과체중·비만 동반 시)
